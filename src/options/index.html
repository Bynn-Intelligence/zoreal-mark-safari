ZOREAL Mark

Record service

Where records are fetched from. Records are public; they are fetched without credentials and cached.

Default https://mark.zoreal.com: a record is that address plus its id, the same page a person opens. A local setup uses http://localhost:<port>/mark.

API

Where sign orders are created and polled.

Default https://api.zoreal.com. A localhost origin is a development server and the only case in which trust anchors are read from the service.
Where the API is mounted on that origin: /v1 in production, /api/v1 on a local Rails.
